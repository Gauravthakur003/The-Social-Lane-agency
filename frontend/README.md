# The Social Lane — Vite Frontend

A complete React + Vite agency frontend inspired by the supplied The Social Lane logo, homepage reference and 2026 portfolio PDF.

## Navigation behavior

React Router is used for every nav item:

- `/` — Home
- `/services` — Services
- `/portfolio` — Portfolio
- `/about` — About Us
- `/blog` — Blog
- `/contact` — Contact

Clicking a navigation item changes the route and shows only that page component. The entire site is NOT rendered as one long page.

## Install

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Notes

The homepage follows the uploaded reference direction: white/navy/blue palette, compact navigation, left-aligned impact headline, creative campaign visual on the right, brand strip and CTA. Portfolio/service copy is grounded in the supplied 2026 portfolio PDF.
